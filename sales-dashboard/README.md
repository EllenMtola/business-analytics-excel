# Sales Dashboard
## Overview

The Sales Dashboard is an interactive Microsoft Excel project designed to analyze sales performance and provide business insights through data visualization. The dashboard summarizes key performance indicators (KPIs) such as Total Sales, Total Profit, and Total Quantity Sold, enabling users to monitor business performance and make informed decisions.

## Objectives
Analyze sales performance across different regions and product categories.
Monitor key business metrics using interactive dashboards.
Identify sales trends and profitable product categories.
Enable users to filter data for better decision-making.
## Features
- Total Sales, Total Profit, and Total Quantity KPI cards
- Regional sales analysis
- Product category analysis
- Monthly sales and profit trends
- Interactive charts and PivotTables
- Dashboard filters using slicers and drop-down controls

## Key Insights
The dashboard provides a clear overview of sales performance by highlighting trends across regions, months, and product categories. Interactive filters allow users to explore the data from different perspectives, making it easier to identify high-performing products, profitable regions, and seasonal sales patterns.


This project demonstrates how Microsoft Excel can be used to transform raw sales data into an interactive business intelligence dashboard. The dashboard supports data-driven decision-making by presenting complex information in a simple, visual, and user-friendly format.
