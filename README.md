# Business Analytics with Excel

## Overview

Welcome to my **Business Analytics with Excel** repository! This repository showcases Excel-based data analytics projects that demonstrate skills in data cleaning, analysis, visualization, dashboard creation, and predictive modeling. Each project applies business analytics techniques to solve real-world problems and present actionable insights.

## Projects

### Sales Dashboard
An interactive Excel dashboard that analyzes sales performance using KPIs, PivotTables, PivotCharts, and interactive filters. The dashboard provides insights into sales trends, regional performance, product categories, and overall business performance.

**Skills:** Data Cleaning, PivotTables, PivotCharts, Dashboard Design, KPI Reporting, Data Visualization

---

### Restaurant Tips Prediction
A predictive analytics project that estimates restaurant tips using Microsoft Excel. The project includes data cleaning, feature encoding, correlation analysis, multiple linear regression, and model evaluation using RMSE to compare actual and predicted tip values.

**Skills:** Data Cleaning, Feature Engineering, Correlation Analysis, Regression Analysis, Predictive Analytics, Model Evaluation

## Tools & Technologies

- Microsoft Excel
- PivotTables & PivotCharts
- Data Analysis ToolPak
- Excel Functions (IF, CORREL, SUMIFS, COUNTIFS)
- Charts & Data Visualization

## Purpose

This repository highlights my ability to use Microsoft Excel for business intelligence, dashboard development, and predictive analytics to transform raw data into meaningful insights.
