# Excel E-Commerce Dashboard

## Project Overview

This project analyses e-commerce sales using Microsoft Excel. The dashboard provides an interactive view of business performance through charts, Pivot Tables, KPIs, and slicers.

## Objectives

- Analyse total sales
- Track monthly profit
- Compare regional performance
- Analyse product categories
- Display key business KPIs

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
